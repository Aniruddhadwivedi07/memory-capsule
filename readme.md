## 📌 Project Overview
**Memory Capsule** is a visually immersive web application that allows users to explore historical events, births, and deaths from any given date.  

The project transforms raw historical data into a **beautiful, interactive timeline experience**, enabling users to discover meaningful moments from the past and curate their own personal memory collection.

---

## 🎯 Objective
The goal of this project is to:
- Demonstrate strong understanding of **JavaScript fundamentals**
- Integrate and work with a **public API using fetch**
- Implement **searching, filtering, and sorting using array higher-order functions**
- Build a **responsive and visually appealing UI**

---

## 🌐 API Used
This project uses the free public API:

👉 https://history.muffinlabs.com/

### Example Endpoint:
```
https://history.muffinlabs.com/date/{month}/{day}
```

### Data Provided:
- 📜 Historical Events  
- 🎂 Births  
- ⚰️ Deaths  

---

## ✨ Features (Planned)

### 🔍 Search Functionality
- Search historical events using keywords (e.g., "India", "war", "technology")
- Implemented using JavaScript array methods like `.filter()`

---

### 🎯 Filtering
- Filter results by:
  - Events
  - Births
  - Deaths  
- Dynamic UI updates based on selected category

---

### 📊 Sorting
- Sort results by year:
  - Ascending (Oldest → Newest)
  - Descending (Newest → Oldest)
- Implemented using `.sort()`

---

### ❤️ Favorites System
- Users can mark events as favorites
- Stored using **localStorage** for persistence

---

### 🌙 Dark / Light Mode
- Toggle between themes for better user experience
